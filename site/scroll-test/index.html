Scroll-tracked character

The rig asked for in comment 18, running against the mesh we currently have. Scroll and he turns; the turn is driven by how far through this section you are, not by the cursor.

This mesh is not the one to ship. It has no skeleton — 0 skins, 0 animations — so nothing on it can be posed or animated; it can only be rotated as one solid object. And it came from a single photograph, so it is only accurate from the front: push the yaw past about 40° with the slider and the face flattens into a plane and the back of the head is a featureless shape. Everything else here is finished and waiting — dropping a rigged .glb at the same path is the whole remaining job.

Past the end of the track the character holds his last pose, so the section can be followed by anything without a snap back.
